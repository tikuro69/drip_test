# Drip Test

A small JavaScript / Canvas experiment for drawing paint splashes and dripping colors.

Click on the canvas to create a paint splash.  
The paint spreads, splatters, and slowly drips down the wall.

## Demo

This project is a simple browser-based visual test.

## Features

- Paint splash effect on click
- Random splatter particles
- Dripping paint animation
- Multiple paint colors
- Canvas-based drawing
- Save the canvas as a PNG image with a timestamped filename
